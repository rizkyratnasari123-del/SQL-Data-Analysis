# World Life Expectancy – SQL Data Cleaning Project

## Project Overview

This project performs a **complete SQL data cleaning workflow** on the World Life Expectancy dataset.
The objective is to improve data quality, handle missing values, remove duplicates, and prepare the dataset for reliable analysis.

## Data Cleaning Process

* Detect and remove **duplicate records** using window functions
* Fix **missing categorical values** in the Status column using self-join logic
* Interpolate **missing Life Expectancy values** using neighboring years
* Validate cleaned data for analytical readiness

## SQL Skills Demonstrated

* Window Functions (`ROW_NUMBER`)
* Self Join
* Conditional Update
* Data Interpolation
* Data Quality Validation
